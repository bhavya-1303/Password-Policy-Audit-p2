# Password Policy Audit – InternCircle Project 02

## Project Overview
This project reviews existing password policy rules, identifies weaknesses, and proposes improved password security practices.

## Project Objectives
- Audit the existing password policy.
- Identify weak rules and recommend changes.
- Develop an improved password policy.
- Create a simple staff password safety guide.
- Promote password managers, multi-factor authentication (MFA), and breached-password screening.

## Project Deliverables
1. **Password Policy Audit** – Reviews existing rules, decisions, reasons, and references.
2. **Improved Password Policy** – Provides eight practical password security rules.
3. **Staff Password Safety Guide** – Explains three simple steps for safer password practices.

## Key Security Recommendations
- Use long, unique passwords.
- Use an approved password manager.
- Enable multi-factor authentication.
- Block common and compromised passwords.
- Change passwords promptly if they are exposed or compromised.
- Allow passphrases and password-manager autofill where possible.
